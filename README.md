# מסלול ההון: האתר המלא (GitHub + Netlify)

אתר קורס השקעות בעברית לפי *המשקיע הנבון*, עם **בדיקת מניות לפי גרהם על כל חברה אמריקאית**. הדוחות נמשכים בזמן אמת מ-SEC (הרשות לניירות ערך בארצות הברית), בחינם ובלי מפתח.

## מה יש בתיקייה

| קובץ או תיקייה | מה זה |
|---|---|
| `public/index.html` | האתר עצמו (קובץ אחד מוכן, לא צריך לבנות כלום) |
| `netlify/functions/company.mjs` | שולף חברה מ-SEC ומחזיר את המספרים לבדיקה |
| `netlify/functions/search.mjs` | חיפוש חברה לפי סימול או שם |
| `netlify/functions/quote.mjs` | מחיר מניה (לא חובה, ראו סעיף 5) |
| `netlify/functions/_lib/` | הלוגיקה של קריאת הדוחות |
| `netlify.toml` | הגדרות ל-Netlify (אין מה לגעת) |
| `dev/` | בדיקות אוטומטיות. לא נדרש להעלאה, אפשר להשאיר |

## העלאה: שלב אחר שלב

### 1. GitHub
1. נכנסים ל-github.com ופותחים חשבון חינם (אם אין).
2. לוחצים **New repository**, נותנים שם (למשל `masluol-hon`), בוחרים Private או Public, ו-**Create repository**.
3. בעמוד שנפתח לוחצים **uploading an existing file**.
4. פותחים את התיקייה במחשב וגוררים לתוך הדף את **כל מה שבתוכה** (`public`, `netlify`, `dev`, `netlify.toml`, `package.json`, `README.md`). חשוב לגרור את התוכן ולא את התיקייה החיצונית.
5. מחכים שההעלאה תסתיים ולוחצים **Commit changes**.

### 2. Netlify
1. נכנסים ל-app.netlify.com, **Add new site → Import an existing project → GitHub**, ומאשרים גישה.
2. בוחרים את המאגר. את שדות ה-Build אין צורך למלא: ההגדרות כבר ב-`netlify.toml`. לוחצים **Deploy**.
3. אחרי דקה האתר חי בכתובת `משהו.netlify.app`.

### 3. הגדרה אחת חובה: זהות מול SEC
ה-SEC דורש שמי שמושך ממנו נתונים יזדהה עם כתובת מייל.
1. ב-Netlify: **Site configuration → Environment variables → Add a variable**.
2. שם: `SEC_USER_AGENT`
3. ערך: `MasluolHon contact your-email@gmail.com` (אותיות באנגלית, וכתובת מייל אמיתית שלכם).
4. **Deploys → Trigger deploy → Deploy site** (כדי שהשינוי ייכנס לתוקף).

### 4. בדיקה שהכול עובד
פותחים בדפדפן (מחליפים את הכתובת בכתובת של האתר שלכם):
- `https://האתר-שלכם.netlify.app/api/company?symbol=KO&debug=1`

אמורים לראות טקסט שמתחיל ב-`{"ok":true`. אם רואים `"ok":false`, שולחים לי את הטקסט המלא ואתקן. אחר כך נכנסים לאתר, לדף "בדיקת מניה אמיתית", ומחפשים `coca` או `AAPL`.

### 5. מחיר חי (לא חובה)
ה-SEC נותן דוחות אבל לא מחירים. בלי שירות מחירים האתר מבקש מהגולש להזין מחיר (והכול עובד). כדי שהמחיר יופיע לבד:
1. נרשמים לשירות מחירים עם מפתח חינמי, למשל finnhub.io.
2. מוסיפים ב-Netlify שני משתנים: `QUOTE_PROVIDER` = `finnhub` (או `alphavantage` או `twelvedata`), ו-`QUOTE_API_KEY` = המפתח.
3. מפעילים Deploy מחדש.

**לפני שמפעילים באתר ציבורי:** בודקים בתנאי השימוש של השירות שמותר להציג את המחירים לגולשים. בתוכניות החינמיות לעיתים מדובר בשימוש אישי בלבד, והמחירים מושהים.

### 6. עדכונים בהמשך
כל שינוי בקבצים ב-GitHub (או קובץ חדש שמעלים) מפעיל Deploy אוטומטי ב-Netlify.

## מגבלות שחשוב להכיר
- רק חברות שנסחרות בארצות הברית (כולל חברות ישראליות שרשומות שם, כמו צ'ק פוינט, טבע ואלביט). חברות שנסחרות רק בתל אביב לא נתמכות.
- רק חברות שמדווחות בדולרים.
- בנקים, חברות ביטוח וקרנות: האתר מסרב או מזהיר, כי מבחני גרהם לא מתאימים להן.
- ב-SEC יש היסטוריה דיגיטלית של כ-15 שנה, ולכן רצף דיבידנד של 20 שנה אי אפשר לאמת אוטומטית. האתר מבקש מהגולש להשלים את הנתון.
- המאגר מסווג סעיפי דוח אוטומטית. ייתכנו שגיאות בחברות עם דיווח לא סטנדרטי, ולכן האתר מציג בכל בדיקה את הסעיפים שבהם השתמש ואת הקישור לדוחות ב-SEC.

## חשבון דמו ושמירה בענן

מסך "חשבון דמו" נשמר קודם כל בדפדפן. כשהמשתמש לוחץ "שמירה בענן" הוא מקבל קוד אישי (16 תווים), והחשבון נשמר ב-Netlify Blobs (שירות אחסון מובנה ב-Netlify, בחינם, ללא הגדרות) דרך הפונקציה `netlify/functions/demo.mjs`.
אין צורך במשתנה סביבה נוסף. Netlify מתקין לבד את החבילה `@netlify/blobs` בזמן הפריסה (היא מופיעה ב-`package.json`).
מי שמחזיק בקוד יכול לראות ולשנות את החשבון. אי אפשר לשחזר קוד שאבד.
